# Forecast_Dashboard

The project involves developing an **interactive forecasting dashboard** using **Streamlit** to predict potential disease outbreaks based on environmental factors. The dashboard integrates **temperature, humidity, and rainfall** data as key predictors against historical disease case records, enabling users to visualize trends and anticipate disease incidence in real time. By leveraging these environmental variables, the system provides actionable insights that can assist public health authorities, epidemiologists, and researchers in planning timely interventions, resource allocation, and preventive strategies. The dashboard features intuitive visualizations, including graphs and charts, making complex data accessible and understandable for both technical and non-technical users. Overall, this project demonstrates the practical application of data-driven modeling and interactive visualization in **disease outbreak forecasting**, highlighting the relationship between environmental conditions and public health outcomes.
